# プロフィール・フォロー・遅刻連絡のUI統一（2026-10-05）

> 初回対応の記録。専門種目の常時全展開と遅刻の全画面フォームは、所有者の訂正を受けて[カテゴリの折りたたみと1タップの遅刻連絡](UI-PROFILE-LATE-REVISION-2026-10-05.md)へ更新した。

担当: Codex。所有者からの全体UI統一依頼のうち、専門種目の非対称な展開、フォローボタンの見た目、遅刻のオン操作を担当する。既存の品質検証用worktreeで作業し、本番DB・環境・サービス・公開先は変更しない。

## 調査と受入条件

- プロフィールの専門種目は、所属ブロック側だけチップ、別ブロック側だけ折りたたみになっている。全種目を同じカテゴリ見出しと複数選択ボタンで表示し、所属ブロックを変えても選択済みの種目を保持する。保存失敗では入力を残す。
- フォロー操作は「フォロー」と「フォロー中」で横幅が変わり、通信例外時に保存中が解除されない。共通Buttonで幅を確保し、連打を抑止する。既存の本人限定favoritesのRLS、タイムラインのフォロー絞り込み、成功時イベントを保つ。失敗時は直前の状態へ戻し、結果不明では保存結果を確認してから次の更新を許可する。
- 遅刻連絡は設定用スイッチと、オン時だけ現れる自動保存入力になっている。当日・出席者だけの入口を保ち、共通FormModalで遅刻の有無と任意の連絡事項をまとめて保存する。入口の高さは状態で変えず、保存中は変更・閉じる操作を止める。未保存の破棄確認と保存失敗時の入力保持を既存部品で行う。0件更新を成功にしない。
- フォローの利用調査は実本番の集計だけを対象とし、ユーザーID・氏名・関係の組合せ・秘密値を記録しない。検証用DBの値を本番利用数として報告しない。安全な読み取り経路が確認できなければ未確認とする。
