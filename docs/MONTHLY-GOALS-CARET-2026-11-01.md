# 月ごとの目標と振り返り・返信欄のカーソルずれ・月初のテスト（2026-11-01、担当 Claude）

所有者要望（同日）: 目標を月ごとにも設定できるようにし、振り返りも書けるようにする。返信で改行するとカーソルが1文字ずれる。前日に直した月初のテストを含めて本番へ反映する。

## 変更

- **月ごとの目標と振り返り**: 目標ページ（/goals）に「月ごとの目標と振り返り」を追加。来月・今月・先月は未記入でも並び、それより前は書いた月だけ新しい順に出る。行を押すと、その月の目標（300字）と振り返り（1000字）を1つの画面で編集する。本人だけが読み書きする（他の部員には見せない）。新しい表 `monthly_goals`（1人1か月1行、month は月の1日）と RLS を migration `20261101010000_monthly_goals.sql` で追加（冪等）。削除の権限は付けず、空で保存すると中身が空になる。
- **返信欄のカーソルずれ**: #タグの色付けは、文字を透明にした入力欄の下に同じ文字を重ねている。iOS Safari は textarea の文字を左右3pxずつ内側へ寄せるため（CSSで消せない）、入力欄の折り返しが重ねた層より1文字早くなり、2行目以降でカーソルと文字がずれる。iOS の WebKit のときだけ、重ねる層の左右の余白を3pxずつ足す。#タグ色付けを使う全入力欄（返信・つぶやき・練習記録）に効く。
- **月初のテスト**: `bc9739a`（前日にmaster反映済み、テストのみ）。
