# 遅刻・連絡表示の整理（2026-10-22）

## 開始・受入条件

所有者の「入力後の表示が多い、吹き出しから時計へ変わって分かりにくい、自動保存・保存成功の文字は不要」に対応。統合版と現行master d1a51c6の対象コードは一致。実コンポーネントの合成表示で、遅刻時だけ入口が時計になり、開くと「自動で保存します」が常設されることを再現。以前の出欠記録にも説明を減らす指示があるが、この2件の表示は残っていた。別チャットの発言全文を特定したとは扱わない。

受入条件は入口を吹き出しに固定、遅刻と連絡内容を一箇所で読めること、通常の保存案内を出さないこと。保存待ち・失敗・結果不明の保護、IME変換中の抑止、連打時の直列保存、既存データ/権限/対象日の識別は維持する。問題時は表示変更を戻せる。DBの移行はしない。

## 実装

吹き出しを固定し、閉じたときは「遅刻 · 連絡内容」、理由なしなら「遅刻」、遅刻なしなら連絡内容だけを表示。開いたときの遅刻操作も表示名を「遅刻」に固定、選択状態でON/OFFを示す。自動保存・保存成功の文章と専用余白を削除。送信中は入力欄内の小さい進行アイコンのみ、失敗/結果不明の案内と対処ボタンを維持。保存成功表示用stateを撤去し、保存ロジックは維持。

文言ガイドに通常の自動保存は常設案内/成功通知を増やさない方針を追記。全画面の文言一括削除や他担当のUI変更は含めない。
