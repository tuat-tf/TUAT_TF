# 管理者によるコメント・スプシ返信の削除

2026-09-29 オーナー依頼。ロール名「管理者」の人だけ他人のアプリコメントとスプシ直接返信を削除できる。本人のアプリコメント削除は維持。他人の本文編集は許可しない。システム管理等の権限フラグだけでは削除権を付けない。

削除は認証付きRPCで対象を検証し、アプリ削除とスプシ削除予定を原子的に保存する。APIがGASへ即時反映し、失敗時は反映待ちを表示して毎日同期で再試行する。GASは送信と削除を同じロックで排他し、返信セルだけを空にする。列を詰めず、日付・練習記録・他の返信を維持。識別メモと本文照合、処理中/完了メモによって遅延送信・再試行・途中停止に対応する。不一致なら削除せず反映待ちにする。

削除予定表sheet_reply_deletionsは処理後も受領記録を保持し、古いシート読込みで同じ返信が再挿入されるのをDBで拒否する。RLSで本人（削除者）か管理者だけが受領記録を読め、一般クライアントは改ざんできない。failoverログ対象・PC/クラウドmirror対象に追加し、元コメントとのFKは付けず削除後も保持する。
