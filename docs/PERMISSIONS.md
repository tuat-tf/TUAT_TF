# ロールと公開範囲のガイド

更新: 2026-10-13。権限統一の実装は独立worktreeで検証中。本番反映の状態は[作業記録](ROLE-PERMISSION-UNIFICATION-2026-10-13.md)を確認する。

## ロールの考え方

ロール名は表示用の肩書き。許可する操作は設定で決まり、改名しても変わらない。複数ロールの権限と対象範囲はORで合算する。「全員」は全利用者に自動適用する。

権限を操作群ごとに8項目へまとめる。コメントの種類、OB戦の年度・画面・操作ごとの細かい権限は作らない。

| 群 | 設定項目 | 許可する操作 |
| --- | --- | --- |
| 管理 | システム・大会管理 | システム設定、大会・種目・プログラムの管理、全ノートの閲覧。OB戦の担当操作を含めるにはOB戦運営権限も必要 |
| 管理 | 部員・ロール管理 | 部員とロールの管理、他人のメニュー・ノート・スレッドの編集/削除。システム権限の付与・所属変更は別制限 |
| 管理 | コメント・返信の削除 | 他人のアプリ内コメント・返信の削除。本文編集は投稿者本人のみ。旧スプレッドシート返信の操作は廃止済み |
| 管理 | OB戦の登録・運営管理 | 登録・懇親会・補助担当・組分け・試技順・結果の管理、変更履歴の閲覧 |
| 日々の活動 | 予定・練習場所の管理 | 予定作成と他人の予定を含む編集/削除、練習場所の管理 |
| 日々の活動 | メニュー作成・編集 | メニューの作成、自分の編集/削除、中長距離シートのメニュー編集。対象ブロックを設定すれば他人のメニューも編集 |
| 日々の活動 | 練習の開催状況・中止 | 開催判断中などの表示、練習中止と取消 |
| 日々の活動 | お知らせ作成・編集・削除 | 作成と他人のお知らせを含む編集/削除 |

「管理」の4項目と他人のメニュー編集範囲は「全員」に付けられない。組み込みロールも設定・名前を編集できるが、固定属性と削除保護は維持する。システム管理権限の付与・取消と所属変更はシステム管理者のみ。

## メニューと大会の対象範囲

- メニューの対象は短距離/中長距離の2区分。短距離は旧跳躍・投擲区分も含む。対象設定とメニュー作成・編集は別ロールから取得してもよい。他人の削除には部員・ロール管理が必要。
- OB戦の旧名「OB戦2026」による判定は廃止。現行の共通大会画面と旧互換処理が同じ運営権限を見る。現行OB戦の結果入力・登録管理は担当者のみ。
- 現行OB戦の変更履歴も運営担当者のみ。旧互換処理の履歴には、従来のシステム・部員管理による閲覧条件を保持する。
- 旧互換の結果入力は従来の承認済み現役部員・システム管理者による条件も保持する。共通大会へ移行済みの大会では旧表の通常書込みを凍結する。現行結果画面の担当者限定とは区別する。
- 一般大会は「大会の担当ロール」で、その大会の操作範囲を指定する。指定はロールIDとの関連なので改名に影響されない。OB戦の担当者はロールのOB戦運営権限で設定する。
- 既存の名前による能力は移行時に一度だけ保存する。その後の同名作成・改名・migration再適用で権限を自動付与しない。

## 閲覧・公開・編集は別

- ノートの共有/個人作成は整理方法。下書き/公開、本人・指定編集者・既存管理権限などの閲覧条件を保持する。システム管理者は個人作成/下書きを含む全フォルダを閲覧できる。
- 作者のみ/全員/指定者は編集者の指定。閲覧できることで編集/削除を許可しない。
- メニューの「他ブロックも見る」は一般閲覧を公開済みだけに広げる。本人・編集対象ブロックの下書き閲覧とは別。
- お知らせの通知先ロールは通常の閲覧制限とは別。システム限定のお知らせには専用制限がある。
- 一般部員プレビューでは8権限すべてとメニュー編集範囲を停止する。ロール名と色は表示のため保持する。

画面とDBのRLSの両方で制限する。設定取得の失敗を「権限なし」や「全員許可」に置き換えない。現在の設定と部員への割当は管理画面/DBで確認し、過去ログの人数・名称を現在値にしない。
