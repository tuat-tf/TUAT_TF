# 複数日の出欠・マイページの読み込み表示・流しの自由入力（2026-10-29、担当 Claude）

所有者要望（同日）: ホームの出席確認で複数日にわたる予定の出席をまとめるのをやめ、日ごとに分けて同じ人が重複しないようにする。マイページの読み込み中の表示（スケルトン）が古い円グラフのままなので現行レイアウトに合わせる。「流し」を自由な文字列の1行入力にする。

## 原因と変更

- **出席の重複**: ホーム「今後の予定」のカード（`UpcomingScheduleCard`）が、予定の全日分の出欠行を1つの出席一覧へ渡していた。本番の 11/13〜15 の予定は33人×3日で93行あり、一覧に同じ人が3回並ぶことを読み取り専用の集計で確認した（同じ日に同じ人の行が2つある例は0件。DBは予定・人・日で一意）。予定ページと同じ `ScheduleAttendance` を使い、日ごとに出欠ボタンと一覧を出すようにした。一覧は日ごとの行だけを数え、同じ人の行が重なっても1人として扱う。単日の予定も日付で絞る。使われなくなった `currentAttendanceDate` を削除。
- **マイページのスケルトン**: 練習量グラフの読み込み表示を、円グラフから現行の並び（期間の切替→合計・前期間比→直近7日の棒7本→強度の凡例→この期間の記録）へ変更。リンク一覧を7行に、管理メニューを説明付き1行に合わせた。ローカルで実物と同じ高さ（グラフ350px、リンク394px）を確認。
- **流し**: 記録の入力欄を、本数の数値欄（`type=number`・「本」付き）から1行の自由入力（`input`、例: 100m×3）へ変更。DBの `practice_records.strides` を integer から text へ変える migration `20261029010000_practice_record_strides_text.sql` を追加（冪等）。以前の0は「入力なし」だったため NULL にし、ほかの本数は同じ数字の文字列として残す。`record_has_content` は流しの文字列を中身として数えるよう更新（権限は維持）。表示は数字だけの値を従来どおり「◯本」、それ以外は入力どおりに出す。スプレッドシート連携は流しを文字列として扱い、シートの「0」は入力なしとみなす（以前は「150×2」が1502として取り込まれていた）。
