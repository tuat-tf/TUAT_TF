# 部員一覧の高さと戻る履歴（2026-10-22）

## 開始・受入条件

部員・ロール管理からプロフィールへ進み戻ると循環する問題と、部員一覧の役職あり・なしでカードの高さが異なる問題を修正する。基準は統合版から公開済みの master dd0c1f1。既存差分を保全する。

- 管理→部員→戻る→管理から戻る、で部員へ循環しない。シート設定・ブログ・歴代十傑など共通の戻る処理も確認する。
- 名簿は学年と役職を同じ段へ収め、役職数や長さによってカードを縦に拡大しない。長い内容は一覧で省略し、プロフィールでは全文を維持する。
- データ・役職・権限・保存処理は変更しない。ロールカテゴリの開閉は対象外。
- 合成データで履歴とスマホ幅を検証する。実機未確認を区別し、必須検証と本番 version 確認まで進める。失敗時は既存公開 release を維持・復帰する。

## 原因確認

共通 BackButton の明示戻り先と履歴なし時の戻り先に push を使っている。管理から来た部員・シート画面は強制戻り先が指定され、管理画面を履歴へ再追加するため、次の back が部員・シート画面へ戻る。名簿は学年の下に役職の折り返し行を追加していた。

## 修正・検証

- 履歴を使える画面の強制戻り先を解除。直接開いた場合などの fallback は replace に変更し、戻った先から詳細へ循環する履歴を追加しない。プロフィールの管理者判定と対象部員付き fallback は維持した。
- 共通処理を使う5経路で修正前に循環をテスト再現。管理→部員/シート→戻る→管理から戻る、直リンク、旧ブラウザ判定、back 無反応時の fallback を確認。
- 類似箇所としてノート記事・フォルダ削除後の移動も replace に変更。0件・結果不明・拒否時は移動せず、確認された削除後だけ戻る既存保護を検証した。新規画面へ進む push と FAB の back は変更しない。
- 名簿の役職を学年と同じ2段目に移した。名前と役職は折り返さず、省略された全文はプロフィールに残る。管理一覧も同じ高さに揃えた。ロール管理カテゴリの展開・保存・権限は未変更。
- 合成データのブラウザ確認で修正前は役職なし71px、あり94.75px。修正後は320px/390px幅で役職なし・1件・複数件・学年未設定すべて63px、横はみ出しなし。実機確認ではない。
- 環境・型・対象eslint成功。全Vitest初回の失敗2件は既存削除テストの router.replace モック不足。モックと戻り先の検証を既存テストへ統合し、該当8テスト成功。独立した重複テストは削除した。
`n最終検証: check:environment・型検査・対象eslint・全Vitest（225ファイル、1973テスト）成功。320px幅の管理一覧も全行63pxを確認。これから同一commitの隔離Linux build・smoke後に公開する。
