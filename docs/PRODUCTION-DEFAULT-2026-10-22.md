# 個別修正の本番反映を標準化（2026-10-22）

## 開始・受入条件
所有者の「それを変えて。本番反映毎回躊躇うのは効率が悪い」に基づき、個別修正は検証から本番反映・公開後確認までを含む継続承認へ変更する。rootと統合版の既存差分を保持して規則を一致させる。

## 終了
- 両作業場所のAGENTS.mdとDEVELOPMENT-RULES.mdを更新した。過去の包括的な公開保留を新しい個別依頼に適用しない。
- 今回の投票・ストーリーUI修正にも新方針を適用する。通常の公開について都度の承認を求めない。
- 明示された対象の最新保留、具体的な不具合・主要操作の未確認は理由を示して扱う。必要な検証は担当が進め、確認をユーザーへ丸投げしない。
- 無関係な未公開変更の便乗公開、Vercel設定・課金変更の承認流用はしない。既存のDB保護・公開後version確認を維持する。
- 文書差分とリンクを確認。今回は規則の変更でありbuild/deploy/pushは実施していない。この記録自体はUIの本番反映完了を示さない。
