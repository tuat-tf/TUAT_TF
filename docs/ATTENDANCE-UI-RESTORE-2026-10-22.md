# 出欠UIの復元（2026-10-22）

所有者指摘: 出欠ボタンが小さく、一覧ボタンから人数が見えない。遅刻中の文言と連絡の操作が分かりにくい。
コードで再現: AttendanceResponseの出欠幅64px、ScheduleAttendanceでcompact表示により人数を非表示、isLateが日付によらず遅刻中。ホームでは人数が予定詳細へのリンク内にあり出欠一覧を直接開けない。

受入条件: 出欠を以前の116px以上へ戻し48px高にする。人数を一覧ボタン上へ復元しホーム・予定とも直接一覧を開く。遅刻・連絡は主操作と別段の44px以上のボタン。未来にも通じる遅刻連絡済み表示。丸いチェックは用いない。狭幅では折り返し、人数を隠さない。既存の一覧絞込み・保存・結果不明保護・権限・連絡内容を維持。DB変更なし。失敗時は入力保持と既存の確認操作を維持。
