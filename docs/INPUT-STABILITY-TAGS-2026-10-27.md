# 入力のガタつき・記録の#タグ・直近7日グラフ（2026-10-27、担当 Claude）

所有者要望（同日）: 文字入力時のガタつきを直す。スレッドのメッセージ入力欄が浮いている。練習記録でも #タグ を青文字にし、押したら検索できるようにする（つぶやきと同じ）。マイページの「直近7日」は7日分の棒グラフにしてスペースを使う。スプレッドシートによる予定の追加は廃止。

## 原因と変更

- **入力のガタつき**: 自動伸長の入力欄（`Textarea autoGrow`）は1文字ごとに高さを一度 `auto` に戻して測る。その瞬間に外側のスクロール領域が縮み、位置が詰められる（ローカルで107→55pxを再現）。Chromeはスクロール補正で隠れるが、補正のないiOS Safariでは跳ねとして残る。測る前のスクロール位置を戻すようにし、値を渡す入力欄では1文字ごとの測定を2回から1回にした。
- **練習記録を開いた直後の上書き**: 同じ日の記録の読込が返る前、または再読込時に打った内容を、読込結果（記録なしなら空欄）で上書きしていた。入力が進んでいた場合は上書きしない。
- **スレッド入力欄が浮く**: キーボード表示中は下部タブが隠れるのに、入力欄はタブ分（88px）の余白を保ったままだった（Android等で画面高が縮む場合）。キーボード表示中だけキーボード直上8pxへ付ける。キーボードを閉じると従来どおりタブの上へ戻る。
- **練習記録の#タグ**: 検索（`search_feed`）は以前から記録の メニュー・目的・結果・補強・感想 を探していたが、表示は青文字・リンクになっていなかった。記録カードとマイページの記録一覧で、この5欄の #タグ を検索へのリンクにした。記録の入力欄もつぶやき同様に入力中から青く表示し、候補を出す。候補の集計に直近1週間の練習記録を追加。独自項目は検索対象外のため色付けしない。
- **直近7日**: ドーナツ図を、1日1本の強度別積み上げ棒7本（横スクロールなし・幅いっぱい・今日を強調）へ変更。合計・前7日比・強度内訳は維持。
- **予定のスプレッドシート入力を廃止**: 画面から開く導線は既になく（FABの予定は月間入力）、未使用の取込画面（`ScheduleCreatePanel`・`ScheduleSheetsManager`・`schedule-sheets/`）と専用の `/api/schedule-sheets/preview` を削除。`/api/schedule-sheets/cron-sync` はPC Jobsのpreflightが参照するため残し、`schedule_sheets` 表・データも変更しない。メニューのスプレッドシート取込は対象外で維持。

DB・migration・権限の変更なし。
