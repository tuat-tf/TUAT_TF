# ノートのフォルダ編集整理（2026-10-22）

所有者の「ルートやフォルダ構造が全部出て分かりにくい」に対応。統合版と対象コードを照合し、メンバー役職表示と一緒に公開する。既存の他担当差分は保全。

## 開始・受入条件

既存コードでは、名前欄より前に移動先の全候補が表示され、編集開始時に一覧取得が走る。通常の編集で階層選択を要求しない。名前・説明・公開状態を先に置き、保存先は明示操作でだけ開く。既存の親、公開範囲、編集権限、競合検出、結果不明の照合、階層制約を維持する。DB構造と既存データは変更しない。

## 変更・検証

- 名前・説明・公開状態を先頭へ移動。「保存先を変更」を押したときだけ共通シートで候補を表示し、初回取得もその時に実施。「ルート」は「ノート一覧」へ変更。
- 同じ種類の再選択で親をリセットしない。別種類への変更時の親リセットは既存仕様を維持。移動候補は自己・子孫・別種類・深さ超過を引き続き除外。
- 候補取得の失敗を空一覧にしない。エラーと再読み込みを表示。保存RPC、expected_updated_atと結果不明時の照合は変更なし。
- 実コンポーネントと合成データで、初期候補取得0回、名前更新時の親/権限/公開状態の保持、明示選択後も更新までは保存0回、更新で選択した親を送信することを確認。自己・子孫・別種類・深すぎる候補は表示されず、失敗表示/再試行も確認。
